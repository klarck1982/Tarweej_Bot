# 🤖 ترويج بوت — v0.8.1 (الخطوة 6 من 6: 🎨 التصميم + 🎫 الدعم + 📣 البث)

بوت تيليغرام لبيع خدمات الترويج (إعلانات فيسبوك/إنستغرام عبر Nour Ads، Telegram Ads، قنوات شريكة، تصميم وكتابة).
مبني بـ Python + aiogram 3، قاعدة بيانات Neon Postgres، استضافة Render (خطة مجانية)، وإبقاء بـ UptimeRobot.

> **ما الذي يعمل؟** الترحيب والشروط، القائمة الملوّنة، الرصيد والشحن (USDT + شام كاش) مع اعتماد الأدمن، معالج إعلان فيسبوك/إنستغرام
> **مرتبط بـ Nour Ads حقيقياً** (مزامنة، استرداد تلقائي، مراقبة رصيد)، 📣 Telegram Ads، 📝 القنوات الشريكة، 🖥️ Cpanel،
> و**🎨 خدمات الكتابة والتصميم** (طلب → تنفيذ يدوي → تسليم → اعتماد/تعديل) مع 🛠️ لوحة المهام،
> **🎫 تذاكر الدعم + 📣 البث + 👤 بحث المستخدم وتعديل الرصيد يدوياً**. «📦 طلباتي»، لوحة الأدمن، `/health` لـ UptimeRobot.
> الإصدار الحالي v0.8.1 — الخطوة 6/6 مكتملة.

## 2) إنشاء الخدمة على Render

1. **New ← Web Service** ← اختر مستودع `promo-bot`.
2. املأ:
   - **Name:** `promo-bot` (سيصبح رابطك `https://promo-bot.onrender.com` — أو أي اسم متاح)
   - **Region:** Frankfurt (الأقرب)
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -m app.main`
   - **Instance Type:** **Free**
3. **Environment ← Add Environment Variable** — أضف هذه بالضبط:

   | Key | Value |
   |---|---|
   | `BOT_TOKEN` | توكن BotFather |
   | `DATABASE_URL` | رابط Neon المجمّع (Pooled) كاملاً |
   | `ADMIN_IDS` | معرّفك الرقمي (وأكثر من واحد بفواصل: `111,222`) |
   | `MODE` | `webhook` |
   | `WEBHOOK_SECRET` | سلسلة عشوائية طويلة من أحرف وأرقام فقط، مثل `k7Qp2ZxW9mL4tR8vB3nH6yJ1` |
   | `TZ` | `Asia/Damascus` |
   | `NOUR_DRY_RUN` | `1` (محاكاة — يصبح `0` في الخطوة 4) |
   | `BOT_NAME` | `ترويج بوت` |
   | `SUPPORT_USERNAME` | يوزر حساب الدعم بدون @ (اختياري) |

   > لا تحتاج `PUBLIC_URL`: Render يوفّر الرابط تلقائياً في `RENDER_EXTERNAL_URL` والكود يقرؤه.
   > (بديل: **New ← Blueprint** يقرأ `render.yaml` وينشئ كل شيء، ثم تدخل الأسرار الثلاثة فقط.)

4. **Create Web Service** ← انتظر 2–3 دقائق حتى ترى في السجل (Logs):
   ```
   INFO db: Postgres pool ready
   INFO db: migration applied: 001_init.sql
   INFO main: webhook set: https://promo-bot.onrender.com/webhook/...
   INFO main: bot @اسم_البوت started — v0.2.3 step 1/6 mode=webhook
   ```
5. ستصلك رسالة على تيليغرام من البوت: **«✅ ترويج بوت انطلق»** ← افتح البوت واضغط **Start** 🎉
   (إذا لم تصل الرسالة الأولى: اضغط Start في البوت أولاً ثم أعد النشر — تيليغرام لا يسمح للبوت بمراسلتك قبل أن تراسله.)

## 3) إبقاء البوت مستيقظاً — UptimeRobot (دقيقتان)

الخطة المجانية في Render تُنيم الخدمة بعد 15 دقيقة بلا زيارات، فيتأخر أول ردّ نصف دقيقة.

1. [uptimerobot.com](https://uptimerobot.com) ← **New Monitor**
2. Type: **HTTP(s)** · URL: `https://promo-bot.onrender.com/health` · Interval: **5 minutes**
3. أضف بريدك للتنبيه إن سقط البوت.

`/health` لا يلمس قاعدة البيانات عمداً — حتى تنام Neon وتبقى ضمن 100 ساعة-حوسبة الشهرية.

## 🆕 ما الجديد في الخطوة 3 (v0.3.0) — معالج إعلان فيسبوك/إنستغرام (وضع محاكاة 🧪)

**التسعير النهائي:** سعر العميل = الميزانية × **1.30** بالضبط (منزلتان، بلا حد أدنى) · تكلفتنا عند نور = الميزانية × 1.10 · الربح = 20% من الميزانية.

| الباقة | الميزانية | السعر | تكلفة نور | ربحك |
|---|---|---|---|---|
| 🚀 تجربة | 2$ × 5 أيام = 10$ | **13$** | 11$ | 2$ |
| 📈 نمو | 3$ × 7 أيام = 21$ | **27.30$** | 23.10$ | 4.20$ |
| 💼 احتراف | 5$ × 10 أيام = 50$ | **65$** | 55$ | 10$ |
| 🛠️ مخصص | من 2$/يوم × 1–30 يوماً | ×1.30 | ×1.10 | 20% |
| 📦 انطلاقة متجر | نمو + نص إعلاني + تصميم صورة | **38$** (بدل 40.30$) | 23.10$ | 14.90$ |

**رحلة العميل (7 خطوات):** الباقة → المنصة (فيسبوك / إنستغرام / كلاهما من 4$ يومياً) → الهدف → الدولة (22 دولة) والمحافظات السورية (14) → الجنس والعمر → الرابط + الوصف + حتى 3 ملفات + خيار «نص إعلاني +5$» → واتساب (مع رمز الدولة، والأرقام المحلية 09… تُكمَّل تلقائياً) → **الملخص والتأكيد** (الخصم يحدث هنا فقط، في معاملة مقفلة واحدة).

- **معرّف تيليغرام:** إن لم يكن للعميل @username تظهر شاشة إرشاد بزر «✅ ضبطته — تحقق»؛ وإن تابع بدونه يُرسل **معرّفك الاحتياطي** لنور (🛠️ لوحة الإدارة → ⚙️ إعدادات → 👤 المعرّف الاحتياطي) وتُعلَّم البطاقة «⚠️ بلا معرّف».
- **رصيد ناقص:** يُحفظ الطلب كمسودة `#ORD-xx` (صالحة 7 أيام)، ويظهر زر «➕ اشحن X$ وأكمل» يقترح المبلغ الناقص بالضبط، ثم «📦 أكمل طلبي المعلّق» في الرصيد والباقات.
- **دورة الحياة:** 🟡 قيد المراجعة → 🔵 قيد التجهيز → 🟢 يعمل → ✅ مكتمل، أو ⏸️ متوقف، أو ❌ مرفوض (**استرداد كامل تلقائي**). كل تغيير يصل العميل برسالة، ومع الاكتمال زر «🔁 إعادة الطلب بنفس الإعدادات».
- **بطاقة الأدمن** لكل طلب: السعر/التكلفة/الربح، الاستهداف، الرابط والوصف، 📎 ملفات العميل، 💬 مراسلة العميل، 🔄 مزامنة، ↩️ استرداد كامل مع سبب يصل العميل.
- **🧪 وضع المحاكاة (`NOUR_DRY_RUN=1`):** لا يُرسل شيء لنور فعلياً؛ الأدمن يحاكي مسار نور من البطاقة: ▶️ قَبِل → 🟢 انطلق → ✅ اكتمل / ❌ رفض. هكذا تجرّب المسار كاملاً بدون صرف دولار واحد.
- **حلقة خلفية داخل نفس العملية** (كل 5 دقائق): إعادة إرسال الطلبات العالقة، إلغاء المسودات المنتهية، ومزامنة الحالات مع نور (تعمل في الخطوة 4 حين يصبح `NOUR_DRY_RUN=0`).
- الترحيل `004_orders.sql` يُطبَّق تلقائياً عند الإقلاع.

### تجربة سريعة بعد النشر
1. تأكد أن رصيد حساب العميل التجريبي ≥ 13$ (اعتمد شحنة من لوحة الأدمن).
2. 📢 إعلان فيسبوك / إنستغرام → 🚀 تجربة → فيسبوك → رسائل → سوريا → دمشق → تم → التالي → أرسل رابطاً → وصفاً → تخطّي → لا → رقم واتساب → ✅ صحيح → **✅ تأكيد الطلب — 13$**.
3. تصلك بطاقة `#ORD-1` كأدمن → اضغط 🧪 ▶️ ثم 🧪 🟢 ثم 🧪 ✅ — وراقب رسائل العميل و «📦 طلباتي».

**📣 البث:** «📣 بث رسالة» → نص حتى 4000 حرف + صورة واحدة اختيارية → معاينة → شريحة (الجميع / لديهم رصيد / طلبوا سابقاً / لم يطلبوا بعد) → تأكيد، وتأكيد إضافي إذا تجاوز الجمهور 50. الإرسال حتى 20 رسالة/ثانية، واستبدال `{name}` باسم العميل، ومن حظر البوت يُعلَّم تلقائياً ويُستثنى من البث القادم. لا توجد أزرار داخل رسائل البث.

**👤 البحث وتعديل الرصيد:** ابحث بـ Telegram ID أو `@username` أو `#ORD-رقم`، فتظهر بطاقة المستخدم والرصيد والطلبات والتذاكر والحظر. «➕ إضافة رصيد» و«➖ خصم رصيد» يتطلبان مبلغاً وسبباً، ثم شاشة ملخص وتأكيد تحمل المبلغ؛ لا يمكن جعل الرصيد سالباً. كل حركة تسجّل في `ledger` بنوع `adjustment` مع الأدمن والسبب داخل معاملة وقفل `FOR UPDATE`، ويصل العميل إشعاراً بالرصيد الجديد. الحظر يمنع الطلبات الجديدة ولا يمس الطلبات أو الرصيد السابق.

### تجربة سريعة بعد النشر
1. من حساب عميل: 💬 الدعم → 🎫 فتح تذكرة → سؤال عام → أرسل رسالة. من بطاقة الأدمن اضغط ↩️ رد، ثم ✅ إغلاق.
2. من `/admin`: 👤 بحث عن مستخدم → ابحث بـ `@username` → ➕ إضافة رصيد → اكتب `5 تعويض اختبار` → راجع الملخص → أكّد.
3. من `/admin`: 📣 بث رسالة → اكتب النص → بدون صورة → اختر الشريحة → أكّد. لا تستخدم بثاً حقيقياً قبل مراجعة الجمهور.
